# Case01: lottery-fewshot-extraction
彩票开奖信息 Few-Shot 提示词抽取 Demo

## ✨ 案例简介
提示词工程入门项目，基于 Few-Shot（少样本学习）构造对话示例，调用大模型兼容接口，从非结构化彩票开奖文本中，稳定抽取 **期数、中奖号码、一等奖** 三个字段，输出标准 JSON。
适合学习：对话式 FewShot 构造、消息列表组装、固定格式输出约束。

## 📌 任务规则
- 输入：一段自然语言描述的彩票开奖文本
- 输出：JSON 对象，固定 key：`期数`、`中奖号码`、`一等奖`
- 中奖号码：红球在前，篮球放在数组最后
- 信息缺失：字段值填写 `原文未提及`，不省略 key
- 示例对照：
  > 输入：2025年第100期，开好红球22 21 06 01 03 11 篮球 07， 一等奖中奖为2注
  > 输出：{"期数":"2025100","中奖号码":[1,3,6,11,21,22,7],"一等奖":"2注"}
