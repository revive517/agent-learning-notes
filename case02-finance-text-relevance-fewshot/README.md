# Case02: finance-text-relevance-fewshot
金融文本相关性判断 Few-Shot Demo

## ✨ 案例简介
提示词工程 Few-Shot 实战案例，任务为**金融文本相关性判断**。输入一对句子，由大模型判断两句内容是否相关，仅输出 `是` / `不是`。
适合学习：构造成对样本、对话式FewShot组装、文本语义匹配任务。

## 📌 任务规则
- 输入：一组两句文本（金融相关句子对）
- 输出：只能是 `是` 或者 `不是`，不输出额外解释
- 判断标准：两句表达的核心话题一致、存在关联 → 输出`是`；话题无关 → 输出`不是`

> 示例对照
> 输入句子对：("利率上升，影响房地产市场","高利率对房地产有一定的冲击。")
> 预期输出：是
